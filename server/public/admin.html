Version is the update that is running: its ID on GitHub, then its title. The newest one is at the top of the list at github.com/5w311/DrivePost/commits, so if the IDs match, you're up to date. Running since is when the server last started. Build is a code the server works out from its own pages; it changes when they do, and isn't the same as the ID.

Admin is opened with the passcode set as DRIVE_PASSCODE in the server's .env file. That passcode opens only this page: it isn't a profile's passcode and can't be used as one. Changing it there signs every device out of Admin.
